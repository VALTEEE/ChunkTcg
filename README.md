# OSRS Chunk Roller

A desktop app for rolling random items, NPCs and monsters from your [Chunk Picker](https://source-chunk.github.io/chunk-picker-v2/) map.

## Setup

**Requirements:** [Node.js](https://nodejs.org) (v18 or newer)

```
npm install
```

## Run (without building)

```
npm start
```

## Build the exe

```
npm run dist
```

The exe will be at `dist\win-unpacked\OSRS Chunk Roller.exe`.

## How to use

1. Open the app
2. Open your chunk picker map in a browser and wait for it to load
3. Drag the **⚔ Send to Chunk Roller** button in the app onto your browser bookmarks bar (one-time setup)
4. Click that bookmark while on the chunk picker page — data sends to the app instantly
5. Click **Roll 5** to roll random cards from your map
